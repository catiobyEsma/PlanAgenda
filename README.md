# PlanAgenda

PlanAgenda is a minimalist productivity application designed to help you organize your daily class schedules, exams, and extracurricular activities with timely reminders.

## Features

- **Class Schedule Management:** Keep track of your daily classes and curriculum.
- **Exam Tracking:** Organize and monitor upcoming exams.
- **Extracurricular Activities:** Record and manage activities outside your regular classes.
- **Timely Notifications:** Receive reminders about your lessons, exams, and activities.

## Privacy Policy

### Data Collection

PlanAgenda does not collect, process, or share personal data with third parties.

### Permissions

The application requests notification permission solely to deliver timely reminders about lessons, exams, and activities. This permission supports the app's core functionality.

### Security

PlanAgenda does not collect or transmit personal data to any server, nor does it use personal data for advertising or analytics purposes.
